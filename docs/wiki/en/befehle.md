# Commands

## For players
| Command | What it does | Permission |
|---|---|---|
| `/toolbar` (`/tb`, `/tools`) | Menu: tool slots, belts, hotbar design, sorting, on/off | `mrtoolbar.use` |
| `/toolbar on` · `off` | Turn the tool bar on or off | `mrtoolbar.use` |
| `/toolbar takeback` | All tools from the belts back into your inventory (also works without the mod) | `mrtoolbar.use` |
| `/toolbar sort` | Set sorting exceptions and sort now (also works without the mod) | `mrtoolbar.sort` |

## For the team
| Command | What it does | Permission |
|---|---|---|
| `/mrtoolbar gui` | All online players with mod version and tool slots, a click shows their belts | `mrtoolbar.admin.gui` |
| `/mrtoolbar view <player>` | View a player's belts (read only) | `mrtoolbar.admin.view` |
| `/mrtoolbar debug [player]` | Mod connection, status and tool slots of a player | `mrtoolbar.admin.debug` |
| `/mrtoolbar reload` | Reload config and language files | `mrtoolbar.admin.reload` |
| `/mrtoolbar discord [test]` | Status of the Discord log · send a test message | `mrtoolbar.admin.discord` |
| `/mrtoolbar version` | Version and update status | `mrtoolbar.version` (in `mrtoolbar.player`) |
