# Hotbar-Design

Wie deine Tool-Slots in der Hotbar markiert werden: **Rahmen**, **Ecken**, **Unterstrich**, **Hintergrund** oder eine **Textur** aus deinem Resourcepack - dazu Farbe, Deckkraft, Dicke und Abstand.

Öffnen über:
- den Knopf in `/toolbar`,
- eine eigene Taste (unter **Optionen → Steuerung → MRtoolbar**, standardmäßig nicht belegt),
- „Konfigurieren“ in Mod Menu.

Gespeichert wird auf deinem PC in `config/mrtoolbar.json` - das Design gilt also auf jedem Server mit MRtoolbar.

## Für Resourcepack-Ersteller
Der Stil „Textur“ zeichnet `assets/mrtoolbar/textures/gui/sprites/hud/tool_slot.png` (20×20, Nine-Slice mit 3 px Rand). Sie wird mit der gewählten Farbe eingefärbt - Weiß behält die Originalfarben.
